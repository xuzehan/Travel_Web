## 行程概览

- **Day 1（10/3 周六）· 成都**：四川博物院（上午，免费预约）→ 午餐 → 宽窄巷子＋人民公园 → 太古里/IFS/大慈寺 → 晚餐 → 住天府广场/春熙路一带（成都住宿需自订）
- **Day 2（10/4 周日）· 成都 → 重庆**：武侯祠＋锦里 → 成都博物馆（天府广场，免费预约）→ 取行李 → 成都东站 → 17:42 G3585 高铁回重庆 → 东原星樾
- **Day 3（10/5 周一）· 重庆南岸·南山（黄色路线）**：老君洞 → 黄桷垭老街＋黄葛古道 → 下浩里老街（喝茶）→ 龙门浩老街＋开埠遗址公园 → 南滨路晚餐 → 社会主义学院夜景 →【可选】长江索道
- **Day 4（10/6 周二）· 重庆渝中半岛（蓝色路线）**：三峡博物馆 → 解放碑（午餐）→ 白象居 → 八一好吃街 → 魁星楼 → 洪崖洞夜景 → 观音桥 → 返回东原星樾

## 地图说明

- 底图为**高德地图瓦片**（GCJ-02 坐标系），标签块位置由瓦片实读后标注，非示意画法。
- 蓝色＝第一天路线（渝中半岛），左下角「解放碑周边放大版」按步行顺序标了 1–5，虚线框为顺路可选点。
- 黄色＝第二天路线（南岸·南山），左下角「下浩里·索道周边放大版」标了当天顺序 3/6/7。
- 主图上的**短虚线＝往返住宿段**：早从住宿出发、晚返回同一住宿点；按要求只标方向、不标住宿点位。
- 地图版权归高德地图所有，仅供个人行程使用。

## 美食模块

第一、二天页面里各有一个**按餐次组织的美食模块**：早餐 / 午餐 / 下午茶 / 晚餐 / 夜宵（Day1）/ 特色小吃，每个餐次写清「在哪里吃 + 为什么顺路」，店只保留路线附近或住宿附近的。

每家店显示：**高德店名 · ⭐评分 · 人均 · 区+地址 · 推荐（必点/热门菜） · 高德导航链接**。同名店按"名称匹配优先 → 评分更高"取最热的一家，并注明是哪个店/分店。

> 数据说明：评分/人均/地址来自**高德地图**（用高德 JS API 在无头浏览器里批量抓取，2026-09-29）。高德未收录的 15 家单独列在模块末尾，需现场或在高德里确认店名/分店。

抓取与整理脚本：`work/amap_js.html`（JS API 批量查询）、`work/run_amap_js.js`（Playwright 驱动）、`work/process_amap.py`（同名店择优）。

时间轴已按「时间段 + 餐次」重排（如 08:30 出发 → 08:30-09:00 早餐 → 09:00-11:30 三峡博物馆 → 11:45-13:00 午餐 …），逐站路书里的餐饮只保留时间段和一句话简介，详情统一放在美食模块。

## 手机上怎么看

1. 用手机浏览器打开本页（微信内置浏览器可能无法唤起高德，请点右上角「···」→「在浏览器中打开」）。
2. 页面顶部 4 个按钮：**Day 1 直接跳转《渝中半岛路书》**；Day 2–4 会唤起高德地图并定位当天起点。
3. 页面本身是单文件自包含 HTML（地图与样式都内嵌），可离线打开、可转发。

## 重新生成

页面由脚本生成，数据与脚本在本地工程的 `work/` 目录：

| 脚本 | 作用 |
| --- | --- |
| `work/fetch_data.py` | 抓取天气（Open-Meteo） |
| `work/train.py` | 抓取 12306 车次与票价 |
| `work/map_build.py` | 下载并拼接高德瓦片为底图 |
| `work/draw_map.py` / `work/draw_map2.py` | 在底图上绘制标签块、路线虚线、方向箭头、放大图与图例（第一/二天） |
| `work/build_4day.py` / `work/embed_map.py` / `work/embed_map2.py` | 生成 4 天 2 地与第一、二天详细页 HTML |

重新生成顺序：`draw_map.py` → `build_roadbook.py`（路书模板）→ `embed_map.py` → `build_4day.py`。
