## 行程概览

- **Day 1（10/3 周六）· 重庆渝中半岛**：住宿出发 → 三峡博物馆/人民大礼堂 → 解放碑（午餐）→ 白象居 → 八一好吃街 → 魁星楼 → 洪崖洞夜景 → 观音桥 → 返回住宿
- **Day 2（10/4 周日）· 重庆南岸 · 南山**：老君洞（山上看远景）→ 黄桷垭老街＋黄葛古道（下山步道）→ 下浩里老街（喝茶休息）→ 龙门浩老街＋重庆开埠遗址公园 → 南滨路江景晚餐 → 社会主义学院（傍晚到夜间看山城夜景）→【可选】长江索道过江 → 返回住宿
- **Day 3（10/5 周一）· 重庆 → 成都**：06:32 G8650 重庆北 → 成都东（07:48）→ 大熊猫繁育研究基地 → 宽窄巷子 → 人民公园 → 太古里/春熙路
- **Day 4（10/6 周二）· 成都 + 返程**：武侯祠 → 锦里 → 文殊院 或 杜甫草堂 → 春熙路收尾 → 成都东站/天府机场

## 地图说明

- 底图为**高德地图瓦片**（GCJ-02 坐标系），标签块位置由瓦片实读后标注，非示意画法。
- 蓝色＝第一天路线（渝中半岛），左下角「解放碑周边放大版」按步行顺序标了 1–5，虚线框为顺路可选点。
- 黄色＝第二天路线（南岸·南山），左下角「下浩里·索道周边放大版」标了当天顺序 3/6/7。
- 主图上的**短虚线＝往返住宿段**：早从住宿出发、晚返回同一住宿点；按要求只标方向、不标住宿点位。
- 地图版权归高德地图所有，仅供个人行程使用。

## 美食模块

第一、二天页面里各有一个**美食模块**：把 40 家店按「路线上的店（当天沿线）/ 住处附近（照母山·观音桥）/ 其他备选（位置待确认）」分组，组内再按 **火锅·串串 / 小面·面馆 / 江湖菜·家常菜 / 豆花饭 / 早餐·小吃 / 茶饮·烘焙** 分类。

每家店给出两个直达链接：**大众点评·看评分与差评**（实时口碑、最新差评、网友推荐菜）与**高德搜索**（导航）。

> ⚠️ 数据说明：大众点评的评分与差评需登录后才能查看，且不允许批量抓取。因此本模块**不填写、不编造**任何分数与差评内容，而是提供店铺直达链接；「位置待确认」指搜索到同名店较多、无法确认具体是哪一家，到店前请点链接核对地址。如果你能提供评分数据（截图/导出），可以直接补进这一栏。

逐站路书里的餐饮只保留「时间 + 一句话简介」，详情统一放在美食模块。

## 手机上怎么看

1. 用手机浏览器打开本页（微信内置浏览器可能无法唤起高德，请点右上角「···」→「在浏览器中打开」）。
2. 页面顶部 4 个按钮：**Day 1 直接跳转《渝中半岛路书》**；Day 2–4 会唤起高德地图并定位当天起点。
3. 页面本身是单文件自包含 HTML（地图与样式都内嵌），可离线打开、可转发。

## 重新生成

页面由脚本生成，数据与脚本在本地工程的 `work/` 目录：

| 脚本 | 作用 |
| --- | --- |
| `work/fetch_data.py` | 抓取天气（Open-Meteo） |
| `work/train.py` | 抓取 12306 车次与票价 |
| `work/map_build.py` | 下载并拼接高德瓦片为底图 |
| `work/draw_map.py` / `work/draw_map2.py` | 在底图上绘制标签块、路线虚线、方向箭头、放大图与图例（第一/二天） |
| `work/build_4day.py` / `work/embed_map.py` / `work/embed_map2.py` | 生成 4 天 2 地与第一、二天详细页 HTML |

重新生成顺序：`draw_map.py` → `build_roadbook.py`（路书模板）→ `embed_map.py` → `build_4day.py`。
